# Model Evaluation Script

## Features

This script evaluates the quality of Coaching Advice reports generated by multiple LLM models using the following metrics:
- **BERTScore F1**: Semantic similarity metric (primary metric)
- **NLI Entailment**: Logical consistency metric (how well generated text logically entails reference text, higher is better)
- **NLI Contradiction**: Logical contradiction metric (lower is better)
- **NLI Neutral**: Neutral relationship metric

## Models Evaluated

The script can evaluate multiple models. By default, it looks for the following model directories (these are examples - you need to configure the paths in `evaluate_all_models.py`):

1. GPT-4o
2. GPT-4-Turbo
3. GPT-5.1
4. Claude-Opus-4.5
5. Gemini-3-Pro
6. DeepSeek-V3.2

**Important**: Before running the script, you must:
1. Update the `model_dirs` dictionary in `evaluate_all_models.py` to point to your actual model output directories
2. Ensure each model directory contains a `coaching_advice_report.md` file

## Usage

### Method 1: Using Batch Script (Windows)
```bash
run_evaluation.bat
```

### Method 2: Run Python Script Directly
```bash
python evaluate_all_models.py
```

## Output Files

After running, the following files will be generated in the `Eval` folder:

1. **eval_summary.csv** - Summary comparison table for all models
2. **eval_summary.md** - Markdown format summary report
3. **eval_all_models.csv** - Detailed evaluation results for all models
4. **eval_gpt_4o.csv** - Detailed results for GPT-4o
5. **eval_gpt_4_turbo.csv** - Detailed results for GPT-4-Turbo
6. **eval_gpt_5_1.csv** - Detailed results for GPT-5.1
7. **eval_claude_opus_4_5.csv** - Detailed results for Claude-Opus-4.5
8. **eval_gemini_3_pro.csv** - Detailed results for Gemini-3-Pro
9. **eval_deepseek_v3_2.csv** - Detailed results for DeepSeek-V3.2

## Dependencies

Install the following Python packages:
```bash
pip install bert-score pandas transformers torch
```

**Note**:
- `transformers` and `torch` are used for NLI (Natural Language Inference) evaluation
- On first run, the NLI model (roberta-large-mnli, ~1.3GB) will be automatically downloaded, which may take some time
- If certain evaluations are not needed, you can comment out the relevant code

## Gold Map

The script uses a gold map file as the reference standard. By default, it looks for `eval/gold_map_extended.jsonl` in the project root directory (one level up from the Github folder).

**Important**: You need to update the `gold_map_path` in `evaluate_all_models.py` to point to your actual gold map file location.

## Configuration

Before running the evaluation script, you need to configure:

1. **Gold Map Path**: Update `gold_map_path` in `evaluate_all_models.py` to point to your gold map file
2. **Model Directories**: Update the `model_dirs` dictionary in `evaluate_all_models.py` to point to your actual model output directories

## Notes

- The evaluation process may take several minutes, especially for BERTScore computation
- Ensure all model report files exist: `{model_dir}/coaching_advice_report.md`
- If a model's report does not exist, the script will skip that model and display a warning
- The script assumes it's running from the `Github/Eval` directory
